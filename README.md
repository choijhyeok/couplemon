# CoupleMon

서로의 Mac 화면에 캐릭터와 짧은 말풍선을 띄우는 커플용 macOS 앱입니다.

## 현재 구현

- 모든 Space에 표시되는 투명 플로팅 패널
- 도트 이미지 선택 및 로컬 저장
- Codex pet v1/v2 `pet.json` + `spritesheet.webp` 선택, 검증, idle 애니메이션 재생
- Supabase Realtime Broadcast를 통한 두 Mac 말풍선·이모지 동기화
- macOS 이모지 선택기와 120자 말풍선 입력
- 채팅창 연필 버튼으로 손그림 전송: 8색, 펜 굵기, 되돌리기, 전체 지우기
- 손그림을 보내거나 받으면 캐릭터 위에 접힌 편지지가 도착하고, 클릭하면 펼쳐져 약 2초 뒤 닫힘
- 터미널 모드: 캐릭터를 숨기고 별도 Codex 스타일 창에서 채팅·손그림 송수신, `[Image #번호]` 클릭으로 그림 보기
- 서버 연결·상대 응답 구분, 메시지 수신 확인, 끊김 재시도와 잠자기 복귀 재연결
- 쿼카·수달·커플 반응 CoupleMon 전용 이모티콘 16종
- `나`/`상대`를 구분한 최근 대화 5개 표시
- 내 것·상대 것·커플 공용으로 나뉘며 DB에 보존되는 실시간 Todo List
- 말풍선은 전송·수신 후 5초 뒤 자동으로 숨김
- 캐릭터 우하단 핸들을 드래그하거나 메뉴에서 크기 70~130% 조절
- 메뉴 막대에서 표시 전환, 캐릭터 초기화, 말풍선 삭제
- 메뉴에서 GitHub Release 업데이트 확인·설치 패키지 실행
- `⌃⌥Space` 전역 단축키로 채팅 입력창 열기·닫기
- `⌃⌥T` 전역 단축키로 Todo List 즉시 열기·닫기
- 새 Mac에서도 바로 보이는 내장 Codex 애니메이션 펫

Supabase 설정 전에는 로컬로만 동작하고, 설정 후에는 같은 연결 코드의 상대 Mac으로 실시간 전달합니다.

## 두 Mac 실시간 연결

1. Supabase 무료 프로젝트를 만들고 Connect 화면에서 Project URL과 `sb_publishable_...` key를 복사합니다. 기존 프로젝트의 legacy `anon` key도 지원합니다.
2. Supabase SQL Editor에서 [`Supabase/schema.sql`](Supabase/schema.sql)을 한 번 실행합니다.
3. 각 Mac에서 **실시간 연결 설정…**을 열어 같은 URL, key, 연결 코드를 입력합니다.
4. 한쪽에서 **연결 코드 복사** 후 상대에게 전달하면 편합니다.

메시지와 이모지는 저장하지 않고 Realtime Broadcast로만 전달합니다. Todo만 DB에 저장되며 상대 변경 알림은 같은 채널로 전달됩니다. 연결 코드는 DB 접근 권한 역할도 하므로 외부에 공개하지 마세요.
로그인 없는 2인용 구조라 같은 연결 코드를 아는 기기는 신뢰된 상대방으로 간주합니다.

### 연결됨인데 서로 메시지가 안 올 때

기존 버전의 `연결됨`은 서버 채널 구독 상태만 표시하며, 상대 접속이나 메시지 전달을 보장하지 않습니다.

1. [Supabase 대시보드](https://supabase.com/dashboard)에서 기존 프로젝트 상태를 확인합니다. `Paused`라면 `Restore`로 복구하고 프로젝트가 활성화될 때까지 기다립니다. 무료 프로젝트는 미사용으로 일시 중지될 수 있습니다([공식 안내](https://supabase.com/docs/guides/platform/free-project-pausing)).
2. 두 Mac의 **실시간 연결 설정…**에서 Project URL, Client key, 연결 코드가 모두 같은지 확인합니다. 프로젝트를 새로 만들었다면 양쪽 설정을 바꾸고 `Supabase/schema.sql`도 새 프로젝트에서 실행합니다. 새 프로젝트는 기존 Todo를 자동 복구하지 않습니다.
3. 두 Mac에서 같은 최신 빌드를 실행하고 **지금 다시 연결**을 누릅니다. **연결 오류 및 해결 방법…**에서 최근 오류도 볼 수 있습니다.
4. **실시간: 상대 응답 확인됨** 상태에서 양방향 메시지를 확인합니다. 서버만 연결된 상태는 **서버 연결됨 · 상대 응답 대기**로 표시됩니다. 상대가 이전 버전이면 응답 확인을 지원하지 않으므로 두 Mac 모두 업데이트해야 합니다.

메시지 수신 확인이 8초 안에 오지 않으면 채팅창에 안내가 표시됩니다. 수신 확인이 없다는 것만으로 미전달이 확정되지는 않습니다. 상대가 오프라인일 때 보낸 메시지·이모지·손그림은 저장하거나 자동 재전송하지 않으므로 연결 복구 후 다시 보내세요.

### 손그림 보내기

채팅 입력창에서 **연필 버튼 → 그리기 → 보내기**를 선택하면 두 Mac의 캐릭터 위에 접힌 편지지가 표시됩니다. **편지지를 클릭하면 펼쳐지는 애니메이션과 함께 손그림이 나타나고, 펼쳐진 뒤 약 2초 후 자동으로 닫힙니다.** 오른쪽 위 **X**로 바로 닫을 수도 있습니다. 열지 않은 편지는 클릭할 때까지 기다리고, 여러 장이 도착하면 순서대로 열 수 있습니다. macOS 동작 줄이기 설정에서는 회전·펼침 동작을 간단한 전환으로 대체합니다.

손그림을 보낼 때는 펫이 편지를 내밀어 보내고, 받을 때는 날아온 편지를 받아드는 전용 동작을 재생합니다. 일반 채팅·이모티콘에는 기존 반응을 사용하며, 터미널 모드에서는 펫과 편지 동작을 표시하지 않습니다.

편지가 닫혀도 손그림은 최근 대화에 남습니다. 캐릭터나 채팅 단축키로 대화를 열고 그림을 누르면 다시 크게 볼 수 있습니다. 흰색 펜으로 부분 지우기도 가능합니다. 두 Mac 모두 0.5.9 이상으로 업데이트해야 같은 편지 연출을 볼 수 있습니다. 손그림은 기존 메시지와 동일하게 DB에 저장되지 않으며, 그리거나 대화에서 크게 보는 도중에는 말풍선을 자동으로 숨기지 않습니다.

## 터미널 모드

채팅 입력창의 **그림판 옆 터미널 버튼**이나 메뉴의 **터미널 모드 열기**를 누르면 캐릭터를 숨기고 별도 Codex 스타일 창을 엽니다. 메시지는 입력(`›`)과 응답(`•`) 형태로 표시하고 손그림·이모티콘은 **`[Image #번호]`**로만 표시합니다. 번호를 누르면 이미지를 볼 수 있습니다. 입력창의 **클립 버튼**으로 그림을 그려 보낼 수 있습니다.

기존 실시간 연결, 대화와 작성 중인 메시지를 공유합니다. 터미널에서는 이번 실행 중 최근 200개 메시지를 볼 수 있고, 캐릭터 말풍선은 기존대로 최근 5개를 표시합니다. 메시지와 그림은 기존과 같이 DB에 저장되지 않습니다.

이 모드에서는 메시지·그림을 받아도 캐릭터나 편지가 나타나지 않습니다. **창의 빨간 X를 누르면 CoupleMon 캐릭터 화면으로 돌아갑니다.** 오른쪽 위의 **돌아가기 버튼**이나 메뉴의 **기본 화면으로 돌아가기**로도 복귀할 수 있습니다. 최소화할 때는 터미널 모드를 유지하며 **⌃⌥Space** 또는 메뉴의 **보이기 / 숨기기**로 다시 열 수 있습니다.

## Codex 애니메이션 펫

메뉴 막대의 **Codex 애니메이션 펫 선택…**에서 Codex가 만든 펫 폴더를 선택합니다. 선택 창은 기본적으로 `~/.codex/pets`에서 열립니다.
선택한 펫이나 이미지가 없으면 앱에 포함된 기본 Codex 펫이 표시됩니다.

선택한 폴더의 접근 권한을 유지한 상태에서 PNG/WebP 데이터를 읽고 로컬에 복사합니다. 폴더 주소 끝의 `/` 유무와 관계없이 같은 폴더로 처리합니다. 저장 전후에 검증하며, 선택이 실패하면 기존 펫을 유지합니다.

지원 규격:

- 버전 필드가 없는 v1 `1536×1872`, 또는 `spriteVersionNumber: 2`인 v2 `1536×2288`
- PNG 또는 WebP, `192×208` 셀
- idle 행 6프레임과 hatch-pet 표준 타이밍
- macOS 동작 줄이기 설정에서는 첫 프레임 고정

## 요구사항

- macOS 14 이상
- Swift 5.10 이상

## 실행

```bash
swift run CoupleMon
```

## 테스트

```bash
swift test
```

Xcode 없이 Command Line Tools만 설치된 환경에서는 XCTest를 찾지 못할 수 있습니다. 이 경우 핵심 입력 규칙을 직접 검사할 수 있습니다.

```bash
swiftc Sources/CoupleMon/MessageText.swift Sources/CoupleMon/RealtimeSettings.swift Sources/CoupleMon/DrawingMessage.swift Sources/CoupleMon/UpdateService.swift Sources/CoupleMon/HatchPetContract.swift Sources/CoupleMon/HatchPetPackage.swift Checks/main.swift -o .build/message-check
.build/message-check
```

실제 Realtime SDK로 두 클라이언트의 양방향 메시지·손그림·수신 확인·방 분리·연결 끊김 복구를 로컬 서버에서 검사할 수도 있습니다. Supabase 접속이나 저장된 연결 설정은 사용하지 않습니다.

```bash
python3 Checks/check-realtime.py
```

터미널 모드의 실제 창 전환·이미지 클릭·그림판·닫기·최소화·기본 화면 복귀는 아래 검사로 확인할 수 있습니다. 저장된 실시간 연결을 사용하지 않으며 미리보기 이미지는 `dist/terminal-review`에 저장합니다.

```bash
python3 Checks/check-terminal.py
```

펫 전환·저장 후 복원·그림 전용 보내기/받기 동작은 아래 검사로 확인할 수 있습니다. 검사할 펫 폴더를 추가 인자로 전달할 수 있고 화면 캡처는 `dist/pet-interaction-review`에 저장합니다.

```bash
python3 Checks/check-pets.py
```

## 앱 번들 생성

```bash
./Scripts/package-app.sh
open dist/CoupleMon.app
```

스크립트는 로컬 실행용 ad-hoc 서명을 사용합니다. 외부 배포 시 Developer ID 서명과 Apple 공증으로 교체해야 합니다.

## 설치 패키지 생성

```bash
./Scripts/package-installer.sh
```

생성된 `dist/CoupleMon.pkg`를 다른 Mac에서 열면 `/Applications/CoupleMon.app`에 설치됩니다. 현재 패키지는 개인 테스트용으로 서명·공증되지 않았으므로 macOS가 차단하면 Finder에서 패키지를 Control-클릭한 뒤 **열기**를 선택합니다. 경고 없이 배포하려면 Developer ID Installer 서명과 Apple 공증이 필요합니다.

설치 후 메뉴 막대 하트의 **업데이트 확인…**에서 최신 GitHub Release를 확인할 수 있습니다. 새 버전이 있으면 `CoupleMon.pkg`를 내려받아 macOS Installer를 엽니다.
