# CoupleMon

서로의 Mac 화면에 캐릭터와 짧은 말풍선을 띄우는 커플용 macOS 앱입니다.

## 현재 구현

- 모든 Space에 표시되는 투명 플로팅 패널
- 도트 이미지 선택 및 로컬 저장
- Codex pet v1/v2 `pet.json` + `spritesheet.webp` 선택, 검증, idle 애니메이션 재생
- Supabase Realtime Broadcast를 통한 두 Mac 말풍선·이모지 동기화
- macOS 이모지 선택기와 120자 말풍선 입력
- 채팅창 연필 버튼으로 손그림 전송: 8색, 펜 굵기, 되돌리기, 전체 지우기
- 그림판·그림 확대 화면에서 카카오톡 등 macOS 공유 메뉴로 이미지 공유, PNG 이미지 복사
- 손그림을 보내거나 받으면 캐릭터 위에 접힌 편지지가 도착하고, 클릭하면 펼쳐져 약 2초 뒤 닫힘
- 터미널 모드: 캐릭터를 숨기고 별도 Codex 스타일 창에서 채팅·손그림 송수신, `[Image #번호]` 클릭으로 그림 보기
- 서버 연결·상대 응답 구분, 메시지 수신 확인, 끊김 재시도와 잠자기 복귀 재연결
- 쿼카·수달·커플 반응 CoupleMon 전용 이모티콘 16종
- `나`/`상대`를 구분한 최근 대화 5개 표시
- 내 것·상대 것·커플 공용으로 나뉘며 DB에 보존되는 실시간 Todo List
- 말풍선은 전송·수신 후 5초 뒤 자동으로 숨김
- 캐릭터 우하단 핸들을 드래그하거나 메뉴에서 크기 70~130% 조절
- 메뉴 막대에서 표시 전환, 캐릭터 초기화, 말풍선 삭제
- 메뉴에서 GitHub Release 업데이트 확인·설치 패키지 실행
- `⌃⌥Space` 전역 단축키로 채팅 입력창 열기·닫기
- `⌃⌥T` 전역 단축키로 Todo List 즉시 열기·닫기
- 새 Mac에서도 바로 보이는 내장 Codex 애니메이션 펫
- 이미지 → Claude/Codex 모델링 코드 → 로컬 Blender 실행 → GLB 저장·미리보기·적용
- 기존 2D 캐릭터와 별도로 유지되는 로컬 3D 보관함, 드래그 회전·숨쉬기·메시지 반응

Supabase 설정 전에는 로컬로만 동작하고, 설정 후에는 같은 연결 코드의 상대 Mac으로 실시간 전달합니다.

## 두 Mac 실시간 연결

1. Supabase 무료 프로젝트를 만들고 Connect 화면에서 Project URL과 `sb_publishable_...` key를 복사합니다. 기존 프로젝트의 legacy `anon` key도 지원합니다.
2. Supabase SQL Editor에서 [`Supabase/schema.sql`](Supabase/schema.sql)을 한 번 실행합니다.
3. 각 Mac에서 **실시간 연결 설정…**을 열어 같은 URL, key, 연결 코드를 입력합니다.
4. 한쪽에서 **연결 코드 복사** 후 상대에게 전달하면 편합니다.

메시지와 이모지는 저장하지 않고 Realtime Broadcast로만 전달합니다. Todo만 DB에 저장되며 상대 변경 알림은 같은 채널로 전달됩니다. 연결 코드는 DB 접근 권한 역할도 하므로 외부에 공개하지 마세요.
로그인 없는 2인용 구조라 같은 연결 코드를 아는 기기는 신뢰된 상대방으로 간주합니다.

### 연결됨인데 서로 메시지가 안 올 때

기존 버전의 `연결됨`은 서버 채널 구독 상태만 표시하며, 상대 접속이나 메시지 전달을 보장하지 않습니다.

1. [Supabase 대시보드](https://supabase.com/dashboard)에서 기존 프로젝트 상태를 확인합니다. `Paused`라면 `Restore`로 복구하고 프로젝트가 활성화될 때까지 기다립니다. 무료 프로젝트는 미사용으로 일시 중지될 수 있습니다([공식 안내](https://supabase.com/docs/guides/platform/free-project-pausing)).
2. 두 Mac의 **실시간 연결 설정…**에서 Project URL, Client key, 연결 코드가 모두 같은지 확인합니다. 프로젝트를 새로 만들었다면 양쪽 설정을 바꾸고 `Supabase/schema.sql`도 새 프로젝트에서 실행합니다. 새 프로젝트는 기존 Todo를 자동 복구하지 않습니다.
3. 두 Mac에서 같은 최신 빌드를 실행하고 **지금 다시 연결**을 누릅니다. **연결 오류 및 해결 방법…**에서 최근 오류도 볼 수 있습니다.
4. **실시간: 상대 응답 확인됨** 상태에서 양방향 메시지를 확인합니다. 서버만 연결된 상태는 **서버 연결됨 · 상대 응답 대기**로 표시됩니다. 상대가 이전 버전이면 응답 확인을 지원하지 않으므로 두 Mac 모두 업데이트해야 합니다.

메시지 수신 확인이 8초 안에 오지 않으면 채팅창에 안내가 표시됩니다. 수신 확인이 없다는 것만으로 미전달이 확정되지는 않습니다. 상대가 오프라인일 때 보낸 메시지·이모지·손그림은 저장하거나 자동 재전송하지 않으므로 연결 복구 후 다시 보내세요.

### 손그림 보내기

채팅 입력창에서 **연필 버튼 → 그리기 → 보내기**를 선택하면 두 Mac의 캐릭터 위에 접힌 편지지가 표시됩니다. **편지지를 클릭하면 펼쳐지는 애니메이션과 함께 손그림이 나타나고, 펼쳐진 뒤 약 2초 후 자동으로 닫힙니다.** 오른쪽 위 **X**로 바로 닫을 수도 있습니다. 열지 않은 편지는 클릭할 때까지 기다리고, 여러 장이 도착하면 순서대로 열 수 있습니다. macOS 동작 줄이기 설정에서는 회전·펼침 동작을 간단한 전환으로 대체합니다.

손그림을 보낼 때는 펫이 편지를 내밀어 보내고, 받을 때는 날아온 편지를 받아드는 전용 동작을 재생합니다. 일반 채팅·이모티콘에는 기존 반응을 사용하며, 터미널 모드에서는 펫과 편지 동작을 표시하지 않습니다.

편지가 닫혀도 손그림은 최근 대화에 남습니다. 캐릭터나 채팅 단축키로 대화를 열고 그림을 누르면 다시 크게 볼 수 있습니다. 흰색 펜으로 부분 지우기도 가능합니다. 두 Mac 모두 0.5.9 이상으로 업데이트해야 같은 편지 연출을 볼 수 있습니다. 손그림은 기존 메시지와 동일하게 DB에 저장되지 않으며, 그리거나 대화에서 크게 보는 도중에는 말풍선을 자동으로 숨기지 않습니다.

그림판이나 대화의 그림 확대 화면에서 **카카오톡 공유 → 카카오톡**을 선택하면 macOS 공유 창에서 대화 상대를 골라 보낼 수 있습니다. 내 그림뿐 아니라 받은 그림도 공유할 수 있고, 터미널 모드의 `[Image #번호]` 확대 화면에서도 사용할 수 있습니다. 그림은 흰 배경의 840×600 이미지로 전달합니다. 카카오톡 Mac 앱이 설치되어 있고 공유 확장이 활성화되어 있어야 메뉴에 표시됩니다. 메뉴에 없으면 **이미지 복사**를 누른 뒤 카카오톡 대화방에서 **⌘V**로 붙여넣어 보내세요. 클립보드는 PNG와 TIFF를 제공하므로 붙여넣는 앱이 지원하는 형식을 사용할 수 있습니다. 공유하거나 복사해도 CoupleMon 상대에게 자동 전송되지는 않습니다.

## 터미널 모드

채팅 입력창의 **그림판 옆 터미널 버튼**이나 메뉴의 **터미널 모드 열기**를 누르면 캐릭터를 숨기고 별도 Codex 스타일 창을 엽니다. 메시지는 입력(`›`)과 응답(`•`) 형태로 표시하고 손그림·이모티콘은 **`[Image #번호]`**로만 표시합니다. 번호를 누르면 이미지를 볼 수 있습니다. 입력창의 **클립 버튼**으로 그림을 그려 보낼 수 있습니다.

기존 실시간 연결, 대화와 작성 중인 메시지를 공유합니다. 터미널에서는 이번 실행 중 최근 200개 메시지를 볼 수 있고, 캐릭터 말풍선은 기존대로 최근 5개를 표시합니다. 메시지와 그림은 기존과 같이 DB에 저장되지 않습니다.

이 모드에서는 메시지·그림을 받아도 캐릭터나 편지가 나타나지 않습니다. **창의 빨간 X를 누르면 CoupleMon 캐릭터 화면으로 돌아갑니다.** 오른쪽 위의 **돌아가기 버튼**이나 메뉴의 **기본 화면으로 돌아가기**로도 복귀할 수 있습니다. 최소화할 때는 터미널 모드를 유지하며 **⌃⌥Space** 또는 메뉴의 **보이기 / 숨기기**로 다시 열 수 있습니다.

## Codex 애니메이션 펫

메뉴 막대의 **Codex 애니메이션 펫 선택…**에서 Codex가 만든 펫 폴더를 선택합니다. 선택 창은 기본적으로 `~/.codex/pets`에서 열립니다.
선택한 펫이나 이미지가 없으면 앱에 포함된 기본 Codex 펫이 표시됩니다.

선택한 폴더의 접근 권한을 유지한 상태에서 PNG/WebP 데이터를 읽고 로컬에 복사합니다. 폴더 주소 끝의 `/` 유무와 관계없이 같은 폴더로 처리합니다. 저장 전후에 검증하며, 선택이 실패하면 기존 펫을 유지합니다.

지원 규격:

- 버전 필드가 없는 v1 `1536×1872`, 또는 `spriteVersionNumber: 2`인 v2 `1536×2288`
- PNG 또는 WebP, `192×208` 셀
- idle 행 6프레임과 hatch-pet 표준 타이밍
- macOS 동작 줄이기 설정에서는 첫 프레임 고정

## 요구사항

- macOS 14 이상
- Swift 5.10 이상

## 이미지로 3D 캐릭터 만들기

메뉴 막대 하트에서 캐릭터 로딩을 두 경로로 선택합니다.

- **기존 캐릭터 불러오기**: 기존 Codex 애니메이션 펫·일반 이미지 선택 유지.
- **3D 캐릭터 만들기·불러오기…**: 이미지로 새 3D 캐릭터 생성 또는 기존 GLB 가져오기.

3D 생성에는 로그인된 **Codex CLI 또는 Claude Code CLI**, **Blender 4.2 이상**이 필요합니다. 앱은 일반 설치 경로를 확인하며, 찾지 못하면 **실행 파일 선택 / Blender 선택**으로 직접 지정할 수 있습니다. Blender는 [공식 다운로드](https://www.blender.org/download/)에서 설치합니다. CLI 설치·로그인은 각 도구에서 먼저 완료하세요.

1. **캐릭터 이미지 선택**에서 PNG/JPEG/WebP(20MB 이하)를 고릅니다. 이미지가 PNG로 정규화되고 최대 1536px로 축소됩니다.
2. 캐릭터 이름, Claude/Codex, 필요하면 추가 외형 요청을 입력하고 **3D 생성 시작**을 누릅니다.
3. 이미지 분석·코드 생성 → Blender 모델링·추출 → GLB 검증 → 로컬 저장의 네 단계와 실행 로그를 확인합니다. 진행 막대는 완료된 단계 수이며 AI 생성 시간의 추정 백분율이 아닙니다.
4. 보관함에서 회전하며 미리 보고 **이 캐릭터 적용**을 누릅니다. 다시 실행해도 선택을 복원합니다.

Tripo 및 별도 3D 생성 API를 사용하지 않습니다. **이미지 분석·코드 생성은 선택한 AI 서비스에서 처리되므로 이미지는 해당 서비스로 전송되고 기존 CLI 계정의 이용 한도·요금이 적용됩니다.** 메시·재질·GLB·Blender 원본은 이 Mac에서 만듭니다. 원본 이미지를 참고해 코드로 재구성하므로 정밀한 3D 복원은 아니며, 가려진 뒷면 등은 추정합니다. 단순하고 정면에 가까운 캐릭터 이미지가 적합합니다.

Blender 실행 오류나 GLB 검증 실패는 로그와 이전 코드를 전달해 한 번 자동 수정합니다. **중지**로 실행을 취소할 수 있고, 창을 닫아도 앱 실행 중에는 작업이 계속됩니다. 앱 종료 시 실행 중인 작업은 중지되며 다음 실행에서 자동 재개하지 않습니다. 실패해도 사용 중인 캐릭터는 유지됩니다.

저장 위치:

- `~/Library/Application Support/CoupleMon/3DCharacters/<ID>/`: `model.glb`, 캐릭터 메타데이터.
- `~/Library/Application Support/CoupleMon/3DWorkspaces/<ID>/`: 참고 이미지, 프롬프트, 생성 Python 코드, `source.blend`, `preview.png`, 실행 로그. 보관함에서 **Blender 원본·생성 코드 열기**로 접근합니다.

새 캐릭터 생성 시 머리·팔·다리의 관절 그룹을 함께 만들고, 기존 2D 펫과 같은 **기본·좌우 달리기·손 흔들기·점프·시무룩·기다리기·제자리 달리기·편지 읽기·둘러보기** 10개와 **레벨 아이템 상호작용 11종**, 총 21개 애니메이션을 GLB에 저장합니다. 동작이 빠진 생성 결과는 검증에 실패하며 자동 수정 대상으로 처리됩니다. 보관함의 **동작 → 재생**과 **편지 보내기/받기**로 확인할 수 있습니다. 받은 편지에는 읽기, 보낸 편지에는 손 흔들기와 3D 봉투를 재생하고, 일반 대화에는 여러 반응을 골라 재생한 뒤 idle로 돌아갑니다.

3D 캐릭터는 드래그로 360° 회전합니다. 외부에서 가져온 GLB에 동작이 없으면 기본적인 몸 흔들기·점프 반응을 사용하며, 자체 동작을 포함한 GLB는 해당 클립을 재생합니다. macOS 동작 줄이기 설정에서는 자동 움직임을 줄입니다. 기존 채팅·편지·크기 조절·터미널 모드와 함께 사용합니다. 캐릭터 이동은 투명 창의 빈 영역을 드래그합니다. 2D 캐릭터 선택이나 기본 캐릭터 초기화는 3D 보관함을 삭제하지 않습니다.

### LV·경험치와 3D 장식

캐릭터 위에 **LV와 다음 레벨까지의 XP 바**를 표시합니다. 보낸 채팅은 10XP, 유효한 그림은 25XP, 이모지·CoupleMon 이모티콘은 5XP입니다. 이모지와 일반 문자가 섞인 메시지는 채팅으로 계산합니다. 받은 메시지·그림, 빈 입력, 잘못된 그림에는 적립하지 않습니다. 서버 연결 전 로컬 송신과 터미널 모드 송신도 활동으로 계산합니다.

LV 1에서 시작해 첫 레벨업은 100XP이며, 다음 레벨마다 필요 XP가 50씩 늘어납니다. **최대 LV는 100**입니다. 총 XP와 장착 아이템은 활동할 때마다 이 Mac의 앱 설정에 저장하며, 앱 종료·재실행 후 복원합니다. 캐릭터 교체·초기화로도 유지됩니다. 두 Mac의 XP는 동기화하지 않습니다.

3D 캐릭터 주변에 **LV 2 별, LV 3 하트, LV 5 달, LV 10 왕관**이 배경 장식으로 순서대로 추가됩니다. 이와 별도로 **LV 2부터 LV 100까지 매 레벨 장착 아이템 1개**가 해금됩니다. 별 장난감·하트 인형·비눗방울 막대·달·공·그림 붓·음악 방울·낚싯대·왕관·마법 지팡이가 순환하며, 높은 레벨에서는 고유 색상·추가 구슬·동작 연출 속도가 달라집니다. **LV 100은 전용 트로피·축하 동작**입니다. 총 99개의 레벨별 아이템이 있고, 모든 아이템마다 완전히 다른 모델을 생성하는 대신 11개 계열을 단계별로 변형합니다.

아이템은 해당 캐릭터의 3D 손·팔 동작에 맞춰 움직입니다. 별 돌리기·하트 안기·비눗방울·달과 쉬기·공놀이·붓질·음악 연주·낚시·왕관 인사·마법·100LV 축하의 11종입니다. 캐릭터 우클릭의 **해금 아이템 장착** 또는 보관함에서 선택하며, 상호작용 버튼이나 캐릭터 우클릭으로 재생합니다. 잠시 대화가 없을 때도 장착 아이템과 노는 동작을 자동으로 골라 재생합니다. 잠긴 레벨의 아이템은 장착·상호작용할 수 없습니다.

바탕화면의 캐릭터 발 아래에는 Todo·**▶ 행동**·크기 조절을 같은 크기로 배치한 작은 툴바가 표시됩니다. 행동 창은 캐릭터 옆으로 열리며, **기본 행동 / 도구** 탭으로 나뉩니다. 채팅창을 열지 않아도 기본 행동, 랜덤 행동, 해금한 도구와 노는 동작을 바로 실행할 수 있습니다. 도구 버튼은 장착과 재생을 함께 처리합니다. 행동 버튼을 눌러도 상대에게 메시지가 전송되거나 XP가 적립되지 않으며, 잠긴 아이템 동작은 실행할 수 없습니다.

Todo도 행동 창과 같은 크기의 옆 팝오버로 열립니다. 창 너비나 캐릭터 위치를 바꾸지 않으며, 버튼을 다시 누르거나 닫기·바깥 클릭·Esc로 닫을 수 있습니다. Todo와 행동 창은 한 번에 하나만 표시됩니다. `⌃⌥T` 단축키와 메뉴에서도 같은 Todo 창이 열립니다.

**함께하기** 탭에서 상대에게 **뽀뽀·포옹·하이파이브**를 보낼 수 있습니다. 양쪽 앱이 **0.6.0 이상**이고 같은 커플 방에 연결돼 있어야 하며, 각각 **8MB 이하의 GLB 캐릭터**를 선택해야 합니다. 선택한 캐릭터와 이름은 기존 커플 연결로 자동 공유됩니다. 상대 캐릭터는 내 캐릭터 옆에 나타나며, 전송 중에는 진행률을 표시합니다. 현재 함께하기는 3D 캐릭터끼리 지원합니다.

동작은 상대의 수신 확인 후 양쪽 화면에서 재생되고 약 6초 뒤 원래 자리로 돌아갑니다. 함께하는 동안 랜덤 행동은 잠시 멈췄다가 재개됩니다. 중복 요청은 재생하지 않고, 상대가 터미널 모드이거나 다른 함께하기 동작 중이면 대기 안내를 표시합니다. 연결이 끊기면 버튼을 비활성화하며, 함께하기 버튼으로 XP가 쌓이지 않습니다. macOS 동작 줄이기에서는 이동 대신 하트 효과를 표시합니다.

캐릭터 파일은 `couple_pet_v1` 이벤트로 24KB씩 전송하고 SHA-256 및 GLB 검증 후 `Application Support/CoupleMon/PartnerCharacters`의 방별 캐시에 저장합니다. 방을 바꾸면 이전 상대 표시가 해제됩니다. 생성되는 모델에는 얼굴·손 접촉 기준점을 추가하며, 기존 모델은 머리와 몸의 경계를 기준으로 맞춥니다. `pet_head`와 팔 관절이 없는 외부 GLB는 몸 이동과 회전 중심으로 표현됩니다.

로컬 검증: `python3 Checks/check-couple.py /path/to/model.glb` — 외부 서버에 접속하지 않고 두 실시간 연결과 두 네이티브 창으로 파일 교환, 세 동작, 랜덤 재개, 중복 방지, 방 분리, 재접속을 확인합니다.

**랜덤 행동**은 자동 모드 토글입니다. 켜면 기본 동작과 현재 장착한 도구의 해금 동작을 계속 골라 재생하며, 가능한 경우 같은 행동이 연속되지 않게 합니다. 동작이 끝난 뒤 기본 5초 쉬고 다음 행동을 시작하며, 옆 메뉴에서 **3·5·10·15·30초**로 바꿀 수 있습니다. 켜진 동안 버튼은 **자동 중지**, 툴바 아이콘은 초록색 셔플로 표시됩니다. 행동 창을 닫아도 계속 움직입니다. **자동 중지**를 다시 누르거나 **기본**을 누르면 idle로 돌아갑니다. 특정 행동을 수동 실행하거나 대화를 주고받으면 그 반응을 먼저 재생한 뒤 자동 행동을 이어갑니다. 켜짐 상태와 간격은 앱 재실행 후에도 유지됩니다. 터미널 모드·화면이 숨겨진 동안·동작 줄이기 설정에서는 자동 동작을 쉬며, 숨겨진 동안의 행동을 몰아서 재생하지 않습니다.

모든 장식과 도구는 실제 3D 메시이며 별도 모델 생성이나 다운로드가 필요하지 않습니다. 보관함의 **장식 미리보기**는 LV 1~100을 체험하며, 실제 XP와 장착 기록은 바꾸지 않습니다.

GLB 가져오기는 텍스처·버퍼가 포함된 비압축 GLB 2.0(150MB 이하)을 지원합니다. 렌더러는 번들에 포함한 Three.js를 사용하므로 저장한 캐릭터 표시에 인터넷이 필요하지 않습니다. 생성된 Python은 네트워크와 작업 폴더 밖 쓰기가 차단된 별도 Blender 프로세스에서 실행됩니다. 자동 실행되는 hooks·MCP·플러그인은 사용하지 않습니다.

프롬프트와 참고 자료: [`generation-prompt.txt`](Sources/CoupleMon/Resources/Pet3D/generation-prompt.txt), [`SOURCES.md`](Sources/CoupleMon/Resources/Pet3D/SOURCES.md).

3D 보관함·선택 복원·오프라인 WebGL·회전·실제 Blender 추출 검증:

```bash
python3 Checks/check-3d.py /Applications/Blender.app/Contents/MacOS/Blender
# 실제 Codex 이미지 생성까지 검증 (로그인된 계정의 이용 한도 사용)
python3 Checks/check-3d.py /Applications/Blender.app/Contents/MacOS/Blender --live
```

기본 검사는 AI CLI 응답을 스텁으로 대체하고 실제 Blender를 실행합니다. `--live`만 실제 Codex를 호출합니다. 사용자 캐릭터·기본 설정은 변경하지 않으며 화면은 `dist/pet3d-review`에 저장합니다.

## 테스트

```bash
swift test
```

Xcode 없이 Command Line Tools만 설치된 환경에서는 XCTest를 찾지 못할 수 있습니다. 이 경우 핵심 입력 규칙을 직접 검사할 수 있습니다.

```bash
swiftc Sources/CoupleMon/MessageText.swift Sources/CoupleMon/RealtimeSettings.swift Sources/CoupleMon/DrawingMessage.swift Sources/CoupleMon/UpdateService.swift Sources/CoupleMon/HatchPetContract.swift Sources/CoupleMon/HatchPetPackage.swift Checks/main.swift -o .build/message-check
.build/message-check
```

실제 Realtime SDK로 두 클라이언트의 양방향 메시지·손그림·수신 확인·방 분리·연결 끊김 복구를 로컬 서버에서 검사할 수도 있습니다. Supabase 접속이나 저장된 연결 설정은 사용하지 않습니다.

```bash
python3 Checks/check-realtime.py
```

터미널 모드의 실제 창 전환·이미지 클릭·그림판·닫기·최소화·기본 화면 복귀, 공유용 PNG의 색상·위치·흰 배경과 클립보드 표현은 아래 검사로 확인할 수 있습니다. 저장된 실시간 연결과 시스템 클립보드를 사용하지 않으며 실제 메시지는 전송하지 않습니다. 미리보기 이미지는 `dist/terminal-review`에 저장합니다.

```bash
python3 Checks/check-terminal.py
```

펫 전환·저장 후 복원·그림 전용 보내기/받기 동작은 아래 검사로 확인할 수 있습니다. 검사할 펫 폴더를 추가 인자로 전달할 수 있고 화면 캡처는 `dist/pet-interaction-review`에 저장합니다.

```bash
python3 Checks/check-pets.py
```

## 설치 패키지 생성

```bash
./Scripts/package-installer.sh
```

생성된 `dist/CoupleMon.pkg`를 다른 Mac에서 열면 `/Applications/CoupleMon.app`에 설치됩니다. 현재 패키지는 개인 테스트용으로 서명·공증되지 않았으므로 macOS가 차단하면 Finder에서 패키지를 Control-클릭한 뒤 **열기**를 선택합니다. 경고 없이 배포하려면 Developer ID Installer 서명과 Apple 공증이 필요합니다.

설치 후 메뉴 막대 하트의 **업데이트 확인…**에서 최신 GitHub Release를 확인할 수 있습니다. 새 버전이 있으면 `CoupleMon.pkg`를 내려받아 macOS Installer를 엽니다.
